the longer story.

i'm a computer science student at SRM University-AP, currently based in Bengaluru. i'm targeting software engineering, web development, and AI/ML roles where people value clarity, speed, and software that actually feels good to use.

i got into programming the messy way: trying to customize things, breaking my desktop environment, and spending weekends reading man pages and stack traces to understand why my shell wouldn't start. that curiosity evolved into a deep appreciation for systems that respect the user and don't waste their time.

i care about the entire stack: from frontend responsiveness and thoughtful micro-interactions, up to backend concurrency, API latency, and edge AI deployment. if a developer tool takes 40 minutes of debugging configuration files before you can write a line of code, i consider it a personal insult.

"boring technology, predictable behavior, and fast feedback loops beat clever abstractions every single time."

outside of coursework and projects, i write long-form engineering essays on blog.sooraj.fun, listen to too much lofi hip-hop, and drink strong South Indian filter coffee.
